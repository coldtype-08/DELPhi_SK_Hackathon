## 0. 전략 요약

- 우리는 비개발자 3인 + Claude Code(Claude Max)다. **사람은 스펙과 판단을, Claude는 코드를 담당한다.**
  그래서 이 레포는 "문서 → 코드" 순서로 움직인다. 스펙 문서가 정확할수록 Claude 결과물이 정확하다.
- 평일은 저녁 2~3시간, 주말은 종일. **주말 2번(8/22–23, 8/29–30)이 전체 개발량의 60%다.** 주말 전에 반드시 "주말에 만들 것"의 스펙을 문서로 확정해 둔다.
- 데모는 로컬 실행이 기본(네트워크 리스크 제거). 외부 API는 전부 캐시 스냅샷으로 폴백. **심사위원 상시 접속용 클라우드 배포(Railway)는 별도 트랙으로 병행** — 일정·운용은 `docs/07_DEPLOYMENT.md` (08/14 확정).
- 기획서 §4-3의 계층 분리 원칙을 그대로 지킨다: **모델 호출·데이터 저장·검색을 업무 로직과 분리.** 더 나은 방법이 확인되면 그 계층만 교체한다.

## 1. 완료 기준 (기획서 §5-1을 그대로 옮긴 것)

**해커톤 단계의 완료 기준은 두 개뿐이다.**
1. 대표 Growth Hypothesis **1건의 전 과정 완전 동작** — 08/21 회의로 완주 대표를 **HYP-003(PGTC, 발굴 축)**으로 재지정. HYP-001(청소년)은 회사가 실제 진행 중인 확대와 대조되는 **검증 축**으로 서사가 바뀌었을 뿐 여전히 생성·표시된다 (docs/03 §2)
2. 핵심 시나리오 ①~⑥의 **반복 테스트 통과** (리셋 DB에서 3회 연속)

**정량 기대효과(Data Latency 70%↓ / Insight Latency 50%↓ / 반복 재분류 70%↓ / reviewer acceptance 90%+)는 파일럿 단계에서 baseline과 비교해 검증한다.**
→ 발표·화면에서는 **"목표치"**로만 말하고, 해커톤 산출물로 달성했다고 표현하지 않는다. 단, `reviewer acceptance`는 합성 코퍼스 ground truth로 **참고 수치**를 낼 수 있다 (docs/03 §4, 정의는 docs/02 §5.5: 검토 완료분 중 승인 비율).

## 6. 방법 비교 규칙 (기획서 §4-3)

기획서에 **"결과가 갈리는 지점은 두 가지 이상 방법으로 비교하고, 채택 이유를 기록한다"**고 썼다. 비교 대상은 넷으로 고정한다.

| 비교 지점 | A안 / B안 | 판정 기준 | 시한 |
|---|---|---|---|
| 추출 단위 | 문단 단위 / 문장 단위 | ground truth 재현율 | 8/23까지 |
| Prompt 전략 | 단일 패스 / 추출→검증 2패스 | 재현성(3회 동일) + 지연시간 | 8/24까지 |
| 검토등급 규칙 | A∧B∧C 3체크 / 가중 점수 | 오분류 건수(육안 20건) | 8/25까지 |
| 에이전트 실행 순서 | 순차 / Field Signal 선행 후 병렬 | Critic 차단 후 재시도 횟수 | 8/29까지 |

- **비교당 90분 상한.** 시한 내 결론이 안 나면 **기존 선택을 유지**하고 그 사실을 기록한다.
- 채택 결과는 `docs/DECISIONS.md`에 한 줄 (`- MM/DD [오너] A안 채택 — 이유`). 기록 없는 비교는 하지 않은 것으로 본다.

## 7. Claude Code(Claude Max) 활용 원칙

1. **스펙 먼저**: 새 기능은 해당 docs 문서를 먼저 고치고, Claude에게 "docs/XX 반영해서 구현해줘"라고 시킨다.
2. **Plan mode**: 파일 3개 이상 건드리는 작업은 plan mode로 계획을 먼저 받고 확인 후 실행.
3. **작게 자주**: 한 세션에 한 기능. 끝나면 커밋. 거대한 한 방 금지.
4. **에러는 통째로**: 막히면 에러 메시지·스크린샷을 그대로 붙여넣는다. 요약해서 전달하지 말 것.
5. **절대 규칙 감사**: 기능 완성 후 "방금 코드가 CLAUDE.md 절대 규칙 8개를 어기는지 검토해줘"를 별도 세션으로 돌린다.
6. **매 세션 시작 프롬프트 예시**: "CLAUDE.md와 docs/00, docs/04 읽고 시작해. 오늘 작업: [마스터플랜의 오늘 칸]."
