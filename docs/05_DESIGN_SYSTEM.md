## 1. 브랜드 무드

- 키워드: **oracle(신탁), evidence(근거), spark(신호)**. 네이비 = 잉크·기록, 오렌지 = **처리를 통과한 것**.
- 로고 파일: 원본 `logo.png`(네이비, 라이트 배경용) / `demo/logo-white.png`(어두운 요소 위, 오렌지 점 유지). **로고는 재현하지 말고 파일을 쓴다** — 정적 HTML에서는 data URI로 임베드(`demo/processing-line.html` 참고). 로고 마크를 스피너처럼 돌리지 말 것(로딩 아이콘으로 오독 — 팀장 피드백).
- **아이콘은 직접 그리지 않는다** — [Lucide](https://lucide.dev) (ISC, shadcn 기본). 앱에선 `lucide-react`, 정적 HTML에선 24×24·stroke 2 그리드로 인라인. 그라데이션 칩 안에 넣지 않는다 — 선 아이콘 그대로.
- 차트는 전부 SVG로 직접 제작. **차트 형태는 의미가 정한다**: 소스가 하나뿐인 데이터에 산키 금지(팀장 반려 사례). **화면 속 숫자는 서로 검산되어야 한다**(후보 = 승인 + AE + 반려, 수용률 ↔ KPI).
- **설명이 계속 필요한 비주얼은 제거한다**: 같은 비주얼이 두 번 의심받으면 다듬지 말고 뺀다(덱 S7 흐름 차트 08/12 제거, 처리 스택 카드 08/22 제거 — 위 도면이 이미 같은 말을 하고 있었다).
- 주관적으로 들리는 카피 금지: "필요한 부분만" → **"위험 기반 검토"** (docs/02 §5.5). 수사 금지: 사실만 쓴다 — "v0.1은 회의실에서 정한 게 아닙니다" 같은 문장은 뺀다.
- 지표 증감은 텍스트 화살표(↑↓) 대신 **굵은 SVG 화살표**(stroke 3.5±, 라운드 캡).

### 2.5 최소 이행 — 기존 화면을 세 줄로 옮긴다

전면 재작업이 아니다. `globals.css`의 값만 바꾸면 대부분 따라온다.

```css
/* 1) 배경·경계 값 교체 */
--paper: #FCFCFA;        /* was #F4F6FC */
--card:  #FCFCFA;        /* was #FFFFFF — 카드가 배경에서 떠오르지 않는다 */
--line:  rgba(22,38,97,.16);

/* 2) 카드에서 그림자·라운드 제거 (전역 1줄) */
.card, [class*="card"] { box-shadow: none; border-radius: 0; border: 1px solid var(--line); }

/* 3) 유리 효과 제거 — backdrop-filter 를 쓰던 곳은 헤더만 남긴다 */
```
- **sky 계열(`#5B7CFA`·`#EAF0FF`)은 퇴역**한다. 데이터·SQL 배지는 `--ink-60` + 모노 서체로 구분한다(색이 아니라 서체로).
- 남는 시맨틱 색은 `--ok`·`--no` 둘뿐. 5단계 구분(§3)의 색은 별개로 유지한다.
- **담당·일정**: 토큰 교체와 그림자 제거 = 소정 (8/24). 화면별 미세 조정은 그 뒤 각자. 이 3줄로 안 따라오는 화면이 나오면 그 화면만 개별 처리한다 — 전면 재작업 금지.

## 5. 모션 규칙

재질이 사라진 대신 **움직임이 구조를 설명한다**. 장식이 아니라 상태 전달이 목적이다.

| 종류 | 시간·이징 | 예 |
|---|---|---|
| 마이크로 (hover, 토글) | 140ms `ease` | 버튼, 배지, 탭 |
| 요소 등장 | 700ms `cubic-bezier(.2,.8,.2,1)` + `translateY(30px)` | 카드·층 |
| 수치 | 카운트업 800ms | KPI |
| 스크롤 연동 | rAF 이징 `gap × 0.13` | 아래 §5.5 |
| 흐름 표시 | `stroke-dasharray` 파선 이동 0.9~1.1s linear infinite | 데이터가 흐르는 선에만 |
| 승인 순간 | 체크 스프링 팝 1회 (반복 금지) | claim·가설 승인 |

**금지**: 무한 반복 장식(흐름선·히어로 배경 제외), 300ms 넘는 hover, `prefers-reduced-motion` 무시, **의미 없는 곳의 파선 애니메이션**(주석용 지시선은 정적 파선 — 08/22 도면에서 4개 제거한 사례).

### 5.5 스크롤이 곧 재생 버튼 (08/22 신설)

긴 도면·다단계 설명에는 자동 재생 대신 **스크롤 위치를 재생 위치로 쓴다.** 심사위원이 속도를 쥔다.

```js
// 활성선을 화면 정중앙에 두면 clip = layerCenter 가 수학적으로 성립한다.
//   clip = center + (f − 0.5) × vh × VH/height   →  f = 0.5 이면 오차항이 사라진다
const line = window.innerHeight * 0.5;
const p = (line - svgRect.top) / svgRect.height;   // 0 → 1
```
- **진행선의 끝은 경로 길이(`getTotalLength`)가 아니라 Y 좌표로 잡는다.** 길이 비율로 잡으면 베지어 구간마다 어긋난다(08/22 실측: 층마다 50%↔77% 편차).
- 스크롤을 멈춰도 **흐름 표시는 계속 움직인다** — 노출량은 `clipPath`가 정하고, 파선 애니메이션은 그 안에서 자유롭게 돈다. 둘을 같은 속성(`stroke-dashoffset`)으로 겸하면 하나를 포기해야 한다.
- 끝점은 스크롤 목표를 **이징으로 따라간다**(`gap × 0.13`). 즉시 스냅하면 애니메이션으로 읽히지 않는다.
- **아직 처리되지 않은 단계는 강조색을 켜지 않는다.** 강조 요소를 `.hot` 그룹으로 분리해 진행선이 닿을 때 점등한다 — "이미 다 된 것"처럼 보이지 않게.

### 5.6 아이소메트릭 도면 규칙

`P(x,y,z) = [OX + (x−y)·cos30, OY + (x+y)·sin30 − z]`

- **화면 세로 위치는 `x+y`가 정한다.** 한 줄에 여러 항목을 늘어놓으려면 `x+y`를 고정하고 `x−y`만 바꾼다.
- **가로 글자는 반드시 여러 칸을 가로지른다.** 가로 120px 이동 = iso `x +69, y −69`. 표 안에 글자를 넣지 말고, 밖으로 빼서 지시선으로 잇는다(제도 도면 방식).
- 마름모의 반폭은 `260 × min(t, 300−t) / 150`. **위아래 끝은 좁다** — 긴 라벨을 위쪽 줄에 두지 않는다.
- 라벨 배치는 눈으로 맞추지 말고 **제약 + 충돌 없는 조합 탐색으로 푼다**. 목적함수는 "최대한 벌리기"가 아니라 `퍼짐 − 0.6 × 최대|dx|` — 테두리로 밀려나면 균형이 깨진다.
- 서 있는 물체(화면·깃발)는 평면 밖으로 솟아도 된다. **받침과 글자만** 평면 안에 둔다.

- **넓은 도면·표는 자기 컨테이너에서만 가로 스크롤**(`overflow-x: auto`). 페이지 본체는 절대 가로로 스크롤되지 않는다.
