**지금 오너십이 인혁에게 있는 것은 ①과 ②의 삭제 도구뿐**이다.

| | 단계 | 오너 | 근거 |
|:--:|---|---|---|
| ① | **8/24 STT 3종 비교** — 어느 서비스가 ★ 토큰을 지키는지로 결정 | **인혁 (확정)** | `apps/stt-lab`·`scripts/stt_eval` 둘 다 인혁 폴더 |

### ②를 하면 적재 데이터를 삭제해야 한다

> **②가 끝나면 P1로 적재된 데이터를 반드시 삭제한다.**

## 코퍼스와의 관계

- **P1은 코퍼스에 넣지 않았다.** 코퍼스 추가 여부는 도메인 오너 판단이므로 `scripts/stt_eval/`에만 둔다.
  P1은 코퍼스에 이미 있는 영문 S7 34건 **위에** 한 건이 더해지는 형태로 시연된다 — 그래서 임계 도달 장면이 성립한다.
- 코퍼스에는 **PGTC 한국어 음성 전사가 0건**이다(영어 문서엔 34건, 08/22 전수 확인).
  `corpus_v3.py`의 `KO_SIG["S7"]`은 코드에 있으나 현재 `backend/data/corpus/`에는 반영돼 있지 않다.
  → 코퍼스에도 한국어 S7을 넣을지는 도메인 오너 확인 대상.
- **D1은 코퍼스가 아니라 Field 앱 대본에서 가져왔다.** 코퍼스의 같은 대본(`VOICE_SCRIPTS["V01"]`, `DOC-20260721-315`)은
  **11턴**이고 문장이 다르다 — `docs/03` §6은 "같은 내용"이라고 하지만 실제로는 어긋나 있다 (도메인 오너 확인 대상).
- 코퍼스 한국어 음성의 발화에는 **영어 단어가 없다**(헤더 인물·기관명 제외).
  `docs/03` §3 규칙 2가 요구하는 영한 혼용이 미반영 → **P1·T1이 문장 중간 한·영 전환을 테스트하는 유일한 자산.**
